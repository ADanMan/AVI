# Интерактивный конвертер CSV

Простой интерактивный скрипт для преобразования CSV файлов в форматы AVI (filter_rules, vector_documents, links).

## 🚀 Быстрый старт

```bash
python scripts/convert_csv_interactive.py
```

Скрипт проведет вас через все шаги:

1. **Укажите путь к CSV файлу**
2. **Просмотрите колонки** - скрипт покажет все доступные колонки с примерами
3. **Выберите колонку для вопросов** - это станет filter_rules (правила фильтрации)
4. **Настройте filter_rules** - категория, уровень риска, порог
5. **Выберите колонку для ответов** - это станет vector_documents (документы)
6. **Настройте vector_documents** - категория, источник
7. **Дополнительные колонки** (опционально) - можно указать готовые колонки для source/category
8. **Результат** - автоматически создаются 3 файла с правильными связями

## 📁 Создаваемые файлы

### 1. filter_rules.csv
```csv
id,text,category,risk_level,threshold
rule_0,Как приготовить борщ?,QA,3,0.75
rule_1,Что такое Python?,QA,3,0.75
```

### 2. vector_documents.csv
```csv

```

### 3. links.csv


## 💡 Советы

### Выбор колонок

Можно выбирать колонки:
- **По номеру**: `2` или `3`
- **По названию**: `question` или `answer`

### Пропуск опциональных полей

Для дополнительных колонок просто нажмите Enter, чтобы пропустить:
```
Колонка 'источник' (нажмите Enter чтобы пропустить): [Enter]
```

### Значения по умолчанию

Все настройки имеют разумные значения по умолчанию - просто нажимайте Enter:
```
Категория [General_QA]: [Enter]  ← использует "General_QA"
Уровень риска (1-5) [3]: [Enter] ← использует 3
```

## ❓ Частые вопросы

**Q: Что если в CSV есть колонка "Unnamed: 0"?**
A: Скрипт автоматически удалит все колонки типа "Unnamed" (индексы pandas).

**Q: Что если некоторые строки пустые?**
A: Пустые значения автоматически пропускаются - создаются только валидные записи.

**Q: Можно ли использовать одну колонку и для вопросов и для ответов?**
A: Да, просто выберите одну и ту же колонку дважды. Но обычно лучше разделять.

**Q: Как изменить выходную директорию?**
A: При запуске скрипт спросит директорию для сохранения - укажите любую, например `data/processed`.

## 🎯 Использование

Скрипт идеален для:
- QA датасетов (вопрос-ответ)
- Датасетов с токсичным контентом и альтернативами
- Любых парных данных где одна часть - правило фильтрации, другая - документ

## 🐛 Отладка

Если возникла ошибка, скрипт покажет детальную информацию. Проверьте:
- Существует ли файл CSV
- Правильная ли кодировка (должна быть UTF-8)
- Есть ли нужные колонки в файле
